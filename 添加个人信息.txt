

当然可以！**Fluid 主题** 之所以受欢迎，就是因为它提供了非常精致的个人展示界面。要添加头像、个人简介和社交账号，我们只需要在**主题的配置文件**里像填空一样填好，然后把头像图片放进文件夹即可。

这就带你手把手完成“站长身份”的最后认证！

---

### 第一步：准备头像图片

1. 在你的电脑里找一张喜欢的照片作为头像（建议是正方形，格式为 `jpg` 或 `png`）。
2. 进入文件夹：`D:\myblog\source\`。
3. 在这里**新建一个文件夹**，命名为 **`img`**（专门用来放博客里的图片）。
4. 把你的头像图片放进去，重命名为 **`avatar.png`**（或者 `avatar.jpg`）。

> **检查路径**：`D:\myblog\source\img\avatar.jpg`。

---

### 第二步：修改主题配置文件（关键步骤）

这里我们要修改的是 **主题文件夹内部** 的那个 `_config.yml`。

1. 打开：`D:\myblog\themes\fluid\_config.yml`（用记事本打开）。
2. **设置首页头像和简介**：
* 按 `Ctrl + F` 搜索关键字 **`index`**。
* 找到 **`avatar:`** 这一行，修改路径：
```yaml
avatar: /img/avatar.png  # 这里指向你刚才放图片的路径

```


* 往下看，找到 **`slogan:`**（有的版本叫 `text:`），这里可以写一句你的简短个签，它会显示在首页大图上。


3. **设置“关于我”页面的详细内容**：
* 按 `Ctrl + F` 搜索关键字 **`about`**。
* 找到以下内容并根据你的情况修改：
```yaml
about:
  enable: true
  avatar: /img/avatar.png     # 关于页面的头像
  name: "左左"                # 你的名字
  intro: "一名热爱生活的数码博主" # 你的简短介绍
  icons:                      # 社交图标（不需要的可以删掉或在前面加#号）
    - { class: 'iconfont icon-github-fill', link: '你的github地址', tip: 'GitHub' }
    - { class: 'iconfont icon-mail-fill', link: 'mailto:你的邮箱', tip: '邮件' }

```




4. **保存文件**。

---

### 第三步：完善“关于我”页面的正文

你之前运行了 `hexo new page about`，现在我们可以去写具体的个人简介了。

1. 进入文件夹：`D:\myblog\source\about\`。
2. 用记事本打开 **`index.md`**。
3. 在横线下方的空白处，你可以像写文章一样，详细介绍自己。例如：
```markdown
---
title: 关于我
layout: about
---

## 个人简介
嘿！我是左左。这是一块我用来记录生活和折腾技术的小天地。

## 兴趣爱好
* 📸 摄影
* 💻 折腾博客
* 🎮 电子游戏

很高兴在这里遇见你！

```


4. **保存文件**。

---

### 第四步：一键同步上线

又是我们熟悉的 **GitHub Desktop** 时间：

1. 打开 **GitHub Desktop**，它会发现你新增了图片，修改了配置文件和关于页面。
2. 左下角填入：`update profile and avatar`。
3. 点击 **`Commit to main`**，再点击 **`Push origin`**。

---

### 🌟 最终效果预览

等 1 分钟 Cloudflare 部署完成后，刷新你的博客：

1. **首页**：可能会出现一个精致的小头像（取决于 Fluid 的版本配置）。
2. **关于页面**：点击顶部导航栏的“**关于**”，你会看到一个超级职业的个人名片页，有头像、社交图标和你刚才写的详细简介。

**小贴士**：如果头像没有显示出来，请检查 `_config.yml` 里的路径是否以 `/` 开头（例如 `/img/avatar.png`），并且确保文件名大小写完全一致。

快去试试看，让你的博客正式印上你的个人烙印吧！
