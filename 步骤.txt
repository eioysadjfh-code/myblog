日常如何无痛更新博客？
既然 Cloudflare 已经和你的 GitHub 绑定好了，以后你再也不需要动用小黑框和那些复杂的命令了。日常写文章只需要三步：

第一步：在本地新建文章
电脑进入 D:\myblog\source\_posts\ 文件夹。

你会看到里面有一个 hello-world.md（这是系统自带的示例）。

你可以直接在当前文件夹下右键 -> 新建文本文档，把名字改成 我的第一篇文章.md（注意后缀要从 .txt 改成 .md）。

第二步：写内容
用记事本（或任意文本编辑器）打开这个 .md 文件，在最上方保留类似下面的格式（这叫文章头部信息），然后在下面直接写你的大作即可：

Markdown
---
title: 我的第一篇文章
date: 2026-05-17 12:00:00
tags: [随笔]
---

这里写你的博客正文内容，支持好玩的 Markdown 语法！
第三步：一键发布（只需 5 秒）
打开你下载的 GitHub Desktop 软件。

软件会自动检测到你新建了一篇文章，左侧会显示绿色的加号。

像上次一样：

在左下角 Summary 输入框随便写个字（比如：add new post）。

点击蓝色按钮 Commit to main。

点击顶部出现的 Push origin（推送）。

大功告成！ 软件进度条走完后，Cloudflare 会在 1 分钟内自动捕捉到更新并重新发布。你只需要刷新你的博客网址，新文章就出现了。

🛠️ 进阶小贴士（有空时折腾）
关于中文乱码：用记事本写文章保存时，请务必注意编码选择 UTF-8，否则网页上的中文可能会变成乱码。

换个好看的外观：现在博客是默认的风景主题。如果你想换个精致、极简的中文主题（比如大名鼎鼎的 hexo-theme-fluid 或 hexo-theme-keep），可以去网上搜一下它们的安装教程，只需把主题文件夹下载到你的 themes 目录，并在主 _config.yml 里改个名字，然后再用 GitHub Desktop 软件提交上去，你的博客就会瞬间焕然一新！
